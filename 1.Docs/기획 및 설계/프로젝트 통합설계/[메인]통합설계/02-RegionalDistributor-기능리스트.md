# RegionalDistributor 기능리스트

## 목적
- 국가/지역 단위 독점 유통권을 가진 대리점 계층의 책임을 정의한다.
- 브랜드 본사와 공급사 사이의 계약, rollout, 지원 경계를 분리한다.

## 핵심 기능

### 1. 지역/국가 유통권 관리
- 국가/지역 독점 권리 관리
- 담당 브랜드 목록 관리
- 지역별 운영 허용 범위 관리
- 지역별 정책/규제/세금 기준 반영

### 2. 브랜드 온보딩
- BrandHQ 신규 등록 지원
- 설치 범위와 rollout 일정 조율
- 초기 배포 패키지 전달
- 현지 지원 채널 연결

### 3. 계약/정산
- 대리점 계약 상태 관리
- 라이선스/계약 갱신 추적
- 현지 정산 기준 관리
- 수수료/지원 비용 트래킹

### 4. 지역 운영 대시보드
- 지역별 설치 현황
- 지점 활성화 현황
- 장애/배포/지원 이력 확인
- 브랜드별 운영 상태 요약

## 비책임 범위
- 실제 매장 주문/결제 데이터는 다루지 않는다.
- EdgePos 장치 드라이버나 로컬 DB를 직접 제어하지 않는다.
- BrandHQ의 메뉴/가격/직원 운영 화면을 중복 구현하지 않는다.

## 레거시 연관성
- 레거시 HJ-POS에 직접 존재하던 기능은 거의 없으며, 신규 플랫폼에서 추가로 정의되는 계층이다.
- 다만 배포, 지원, 감사, 정산의 상위 책임은 레거시 운영 기능의 외곽을 흡수한다.
