# BrandHQ 기능리스트

## 목적
- 하나의 브랜드가 여러 지점을 통합 운영할 때 필요한 기능을 정의한다.
- 매장 운영의 정책 원본과 카탈로그 원본을 관리한다.

## 핵심 기능

### 1. 메뉴/카탈로그 관리
- 상품/메뉴 마스터 관리
- 가격 정책과 세금 정책 관리
- 프로모션/할인 이벤트 관리
- 지점별 카탈로그 배포

### 2. 지점 운영
- 지점 생성/수정/정지
- 지점별 override 관리
- 지점 권한 템플릿 관리
- 지점 운영 현황 조회

### 3. 조직/직원 관리
- 브랜드 조직 구조 관리
- 직원 권한/역할 템플릿 관리
- 운영자 계정 분리
- 지점 단위 접근 제어

### 4. 리포트/정산
- 매출 리포트
- 지점별 실적 비교
- 정책별 효과 추적
- 중앙 API를 통한 조회/분석

### 5. EdgePos 연계
- EdgePos로 내려갈 정책/카탈로그 배포
- Setup/Maintenance 모드에서 현장 설정 적용
- 장치 템플릿과 로컬 커미셔닝 정보 관리

## 비책임 범위
- 주문/결제 거래의 실시간 원본은 소유하지 않는다.
- 지역 독점 유통권과 공급사 전체 배포 정책은 SuperAdmin/RegionalDistributor 책임이다.
- 로컬 장치 제어는 BrandPosApp 내부 모드에서 수행한다.

## 레거시 연관성
- `Inventory & Menu`, `Customer`, `System & Admin` 중 브랜드 운영에 필요한 부분을 흡수한다.
- 특히 상품/메뉴/가격/프로모션의 관리 흐름은 BrandHQ의 핵심 책임으로 본다.
