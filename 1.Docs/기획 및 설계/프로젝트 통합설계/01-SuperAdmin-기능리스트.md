# SuperAdmin 기능리스트

## 목적
- 공급사가 여러 브랜드와 대리점을 통합 운영하기 위해 필요한 기능을 정리한다.
- 매장 운영 기능이 아니라, 플랫폼 전체를 통제하는 상위 관리 기능만 다룬다.

## 핵심 기능

### 1. 테넌트/조직 관리
- 대리점(RegionalDistributor) 생성/승인/정지
- 브랜드 본사(BrandHQ) 온보딩
- 지점 계층 연결 및 조직 구조 관리
- 계정 소유권과 운영 권한 이관

### 2. 라이선스/배포 관리
- 브랜드별/지역별 라이선스 발급
- 버전 배포 정책 관리
- 롤아웃 대상 및 단계적 배포 제어
- 배포 실패/재시도/승인 상태 추적

### 3. 정책/감사/보안
- 글로벌 RBAC 정책
- 감사 로그 조회
- 정책 템플릿 배포
- 보안/접근 제어 기준 관리

### 4. 운영 모니터링
- 브랜드/대리점/지점 상태 모니터링
- 장애 알림과 헬스체크
- 원격 지원 기록
- 배포 상태와 동기화 상태 추적

### 5. 중앙 계약 관리
- `SuperAdmin/CentralApi`의 GraphQL contract 관리
- REST 예외 엔드포인트 사용 범위 관리
- `SharedContracts` 버전 관리

## 비책임 범위
- 주문, 결제, 테이블, 재고 같은 매장 원본 데이터는 소유하지 않는다.
- Edge POS의 로컬 장치 연결을 직접 처리하지 않는다.
- BrandHQ의 운영 화면을 중복 구현하지 않는다.

## 레거시 기능과의 연결
- `System & Admin`의 상위 통제 기능을 SuperAdmin으로 승격한다.
- 외부 연동의 관리/정책/감사 계층은 SuperAdmin이 소유한다.
- 레거시 POS의 운영 데이터는 SuperAdmin이 아니라 EdgePos로 귀속한다.
