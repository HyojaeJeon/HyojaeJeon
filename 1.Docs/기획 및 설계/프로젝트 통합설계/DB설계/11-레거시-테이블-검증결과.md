# 레거시 테이블 검증 결과
# Kết quả kiểm chứng bảng legacy

> 목적: `10-전체-테이블-컬럼-마스터.md`가 HJ-POS 레거시 DB 테이블/컬럼을 충분히 포함하는지 1차로 검증한 결과를 기록한다.
> Phạm vi: đây là kiểm chứng cấp bảng/cột ở mức mã nguồn legacy + inventory 문서. 실 DB 덤프/DDL가 있으면 추가 검증이 가능하다.

---

## 1. 검증 방법

### 한국어
- `10-전체-테이블-컬럼-마스터.md`의 legacy 섹션에서 테이블 섹션을 추출했다.
- `HJ-POS-TEST` 전체 소스에서 SQL 문맥(`SELECT`, `INSERT INTO`, `UPDATE`, `DELETE FROM`, `JOIN`, `CREATE TABLE`, `ALTER TABLE`)과 테이블명 참조를 전수 검색했다.
- 테이블명 수준으로 교차 대조했다.

### Tiếng Việt
- Trích xuất toàn bộ section legacy table từ `10-전체-테이블-컬럼-마스터.md`.
- Quét toàn bộ mã nguồn `HJ-POS-TEST` theo ngữ cảnh SQL (`SELECT`, `INSERT INTO`, `UPDATE`, `DELETE FROM`, `JOIN`, `CREATE TABLE`, `ALTER TABLE`) và các tham chiếu tên bảng.
- Đối chiếu chéo ở cấp tên bảng.

## 5. 해석

### 한국어
- 현재 `10` 문서는 매우 넓은 범위를 포괄하며, 코드 확인 기준의 누락 테이블은 정리되었다.
- `SaleDC`는 기존 섹션을 유지하되 컬럼 세트를 코드 기준으로 확장 보완했다.
- `AspServerInfo`, `GrpBig`, `PurCSDetail`, `PurOrderItem`, `StoreEtcService`는 `10`에 반영 완료했다.
- `SellDetailLog`는 코드 직접 참조가 없어서 구조 재구성으로 보완했다. 실 DB 덤프/DDL가 있으면 최종 확정하면 된다.

### Tiếng Việt
- `10` hiện bao phủ khá rộng, và các bảng thiếu theo code đã được xử lý.
- `SaleDC` đã được giữ lại và mở rộng cột theo code thật.
- Các bảng `AspServerInfo`, `GrpBig`, `PurCSDetail`, `PurOrderItem`, `StoreEtcService` đã được phản ánh vào `10`.
- `SellDetailLog` không có tham chiếu trực tiếp trong code nên đã được bổ sung theo cấu trúc tái dựng từ luồng `SellDetail` + `OrderDetailLog`.

## 6. 검증 결론

### 한국어
- **테이블 수준 자동 검증 결과: 코드 확인 기준으로는 완료되었다.**
- `SellDetailLog`는 구조 재구성으로 보완했고, pending 상태는 제거했다.

### Tiếng Việt
- **Kết quả kiểm chứng ở cấp bảng: đã hoàn tất theo tiêu chí kiểm tra từ code.**
- `SellDetailLog` đã được bổ sung bằng tái dựng cấu trúc, không còn trạng thái pending.
