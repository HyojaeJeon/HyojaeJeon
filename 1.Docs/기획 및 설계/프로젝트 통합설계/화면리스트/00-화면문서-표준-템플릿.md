# 화면 문서 표준 템플릿

이 템플릿은 `화면리스트/화면설계,구조,요소/` 아래의 각 화면 문서를 채우는 기준이다.
한 화면 문서는 화면 설계와 구현 명세를 함께 포함해야 한다.
파일 경로 표기는 현재 `BrandPosApp/PosUi` 실제 구조 기준의 `.ts` / `.tsx` 파일명만 사용한다. `.js`는 사용하지 않는다.
