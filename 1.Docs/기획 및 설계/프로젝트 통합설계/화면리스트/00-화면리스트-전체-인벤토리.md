## 부록: 화면 전환 흐름도

```
[로그인] → [메인 메뉴]
              ├── [테이블 화면] → [주문 화면] → [결제 화면]
              │                     ├── 주문 메시지
              │                     ├── 세트메뉴 구성
              │                     └── 상품 상세/옵션
              ├── [배달 관리] → 고객 검색 → 주소 입력 → 주문/결제
              ├── [재고 관리] → 재고 입력/조회/정산
              ├── [장부 관리] → 장부 입력/조회
              ├── [고객 관리] → 고객 등록/검색/상세
              ├── [직원 관리] → 근태 관리
              ├── [매출 조회] → 매출 목록/상세
              └── [마감 처리] → 자동/수동 마감

[키오스크] → [테이블 선택] → [메뉴 선택] → [옵션] → [결제] → [완료]

[주방 디스플레이] → 주문 표시/완료 처리

[테이블오더] → 주문 수신/상태/품절 관리

[설정 앱] → 매장/상품/테이블/결제/인쇄/직원/키오스크/이벤트/기타
```
