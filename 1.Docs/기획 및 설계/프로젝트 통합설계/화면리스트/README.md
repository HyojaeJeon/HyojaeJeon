# 화면리스트

이 폴더는 `BrandPosApp/PosUi`에서 구현할 POS 화면을 정리하는 출발점이다.
레거시 HJ-POS 화면 문서를 기준으로, 각 화면을 구현 단위로 확장한다.

## 작업 원칙

- 한 화면 문서는 한 화면 구현 단위다.
- 상위층에는 화면 목적, 기능, UI 구조, 관련 아키텍처와 DB를 둔다.
- 하위층에는 구현명세, 연동 계약, 테스트, 완료 기준을 둔다.
- 파일 경로 표기는 `BrandPosApp/PosUi` 실제 구조 기준의 `.ts` / `.tsx` 파일명만 사용한다.
- 구현 전에 화면 문서를 먼저 완성하고, 그 문서를 기준으로 `BrandPosApp/PosUi`, Bridge, UseCase, DB, CentralApi 연동과 테스트를 진행한다.
- 구현이 끝난 화면은 해당 문서의 `작업 진행 기록`에 완료 범위와 남은 범위를 반드시 남긴다.
